    Having trouble connecting?

    • Browser works, agent fails: check the agent’s own account and connection. List pools inside the agent.
    • Old personal key or 401: for the terminal or local adapter, remove an explicitly configured PENSIEVE_TEAM_TOKEN and use browser sign-in. Native remote connectors use their host’s reconnect action.
    • Sign-in required: use the host’s reconnect action, run pensieve connect, or ask your local Pensieve MCP agent for connect_pensieve. Open the returned link and retry after approval.
    • Old local adapter still running: reload its MCP connection once after upgrading. The updated adapter loads subsequent sign-ins and renewals without a restart.
    • Missing pool or denied save: ask the pool owner to check membership. Saving and indexing require writer access.
    • Saved but not recalled: confirm the destination and save receipt. Indexing can be queued; retry recall when indexing finishes. Repeated index requests during cooldown do not start duplicate jobs.
    • Rate limit: wait and retry; avoid simultaneous bulk repository uploads from the same network.
